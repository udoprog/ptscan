ptscan

Finds the memory addresses behind the numbers in a running program, the way Cheat Engine does, from a web UI in your browser on Windows and Linux. Run typed value scans, narrow results with an expression language, resolve moving addresses into stable pointer paths, and update with ptscan update.

Install

curl -fsSL https://udoprog.github.io/ptscan/install.sh | sh

Installs into ~/.local/bin (set PTSCAN_INSTALL_DIR to change it) on Linux (x86_64). On Windows, download the zip from the releases.
